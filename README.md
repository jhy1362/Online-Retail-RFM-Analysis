# 电商零售用户RFM分析项目
## 项目简介
基于UCI公开电商零售数据集，使用MySQL完成订单数据清洗、RFM用户分层，对不同客户群体制定差异化运营策略，实现用户精细化运营分析。

## 数据源说明
数据源：UCI公开数据集 Online-Retail
原始数据集一共541910条订单记录
字段：InvoiceNo订单号、StockCode商品编码、Description商品名称、Quantity购买数量、InvoiceDate订单时间、UnitPrice单价、CustomerID用户ID、Country国家。

> 数据说明：原始CSV存在特殊字符，导入MySQL存在字符转换警告；分析时过滤退货、赠品、CustomerID为空脏数据。

## 工具与环境
- 数据库：MySQL 5.7
- 客户端：DBeaver
- 数据集：UCI Online Retail

> 注意：MySQL5.7不支持CTE(WITH)、NTILE窗口函数，本项目采用临时表分步计算RFM打分。

## 数据清洗规则
1. 过滤退货订单：Quantity > 0（负数代表退货）
2. 过滤赠品订单：UnitPrice > 0（单价为0代表赠品）
3. 剔除CustomerID为空的无效数据

## RFM模型介绍
- R（Recency）：最近一次消费距离截止日期的天数，数值越小越活跃
- F（Frequency）：用户消费订单频次，越高代表复购越强
- M（Monetary）：用户总消费金额，越高代表消费能力越强

将客户按R、F、M五分制打分，组合标签完成用户分层。

## RFM用户分层结果
| 用户分层 | 用户数量 | 占比(%) |
| ---- | ---- | ---- |
| 流失客户 | 2861 | 65.94 |
| 新客户 | 381 | 8.78 |
| 重要价值客户 | 349 | 8.04 |
| 重要挽留客户 | 290 | 6.68 |
| 高价值流失客户 | 181 | 4.17 |
| 中频流失客户 | 139 | 3.20 |
| 重要深耕客户 | 90 | 2.07 |
| 重要潜力客户 | 48 | 1.11 |

### 业务解读
1. 流失客户占比高达65.94%，超过三分之二客户已经流失，用户留存问题严重。
2. 重要价值客户仅占8.04%，是平台核心营收群体，人数少、贡献主要收入。
3. 新客户占比8.78%，新客体量有限，需要做好新客二次转化。
4. 重要挽留客户、高价值流失客户合计超过10%，属于历史高消费、近期沉寂客户，召回价值较高。

### 分群体运营策略
1. **重要价值客户（8.04%）**：高消费、高频、近期活跃。提供会员权益、专属优惠券，维稳，防止流失。
2. **重要挽留客户（6.68%）**：历史消费高，近期活跃度下降。发放定向大额优惠券召回。
3. **新客户（8.78%）**：近期首次下单。推送复购券，引导二次购买，提升留存。
4. **高价值流失客户（4.17%）**：消费能力强，长期未下单。低成本触达召回，控制营销投入。
5. **流失客户（65.94%）**：长期无消费。减少营销资源，仅做低成本批量触达。

## 项目文件说明

## 项目总结
本项目使用54万条零售订单数据，完成数据清洗，基于MySQL5.7实现RFM用户分层。识别出平台客户流失严重，核心高价值客户占比偏低，针对不同客户群体输出对应的运营策略，为电商精细化用户运营提供数据支撑。
